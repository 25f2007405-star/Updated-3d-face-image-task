# 3D Face Model Reconstruction (GA3 Submission)

## Overview
This repository contains the reconstructed 3D mesh asset generated for Graded Assignment 3 (GA3). The primary deliverable is a textured, three-dimensional representation stored in binary glTF format (`model-v1(2).glb`).

---

## File Details
- **File Name:** `model-v1(2).glb`
- **Format:** glTF 2.0 Binary (`.glb`)
- **Type:** 3D Mesh (Face Reconstruction with Geometry & Texture)

---

## Reconstruction Methodology
- **Input:** 2D Face Image / Portrait dataset.
- **Processing:** Feature landmark extraction, depth estimation, and 3D surface mesh generation.
- **Output:** Baked UV texture mapping and vertex geometry exported into a compact binary `.glb` package.

---

## How to View the Model
1. **Online GLB Viewers:**
   - Download `model-v1(2).glb` from this repository.
   - Drag and drop the file into [gltf-viewer.donmccurdy.com](https://gltf-viewer.donmccurdy.com/) or [sandbox.babylonjs.com](https://sandbox.babylonjs.com/).
2. **Local 3D Tools:**
   - Open using standard 3D software such as Blender, MeshLab, or Windows 3D Viewer.
3. **Web Integration:**
   - Compatible with Google `<model-viewer>` or Three.js web renderers.
